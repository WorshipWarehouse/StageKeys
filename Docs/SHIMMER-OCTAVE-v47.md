# Shimmer octave tracking — 0.47

The short dual-grain octave path periodically changed the pitch of steady content: a 220 Hz probe produced prominent components around 420/453 Hz instead of a stable 440 Hz octave. The replacement uses an independently implemented, fixed-storage phase vocoder on the already diffused wet return. It estimates bin frequencies between overlapping frames and synthesizes the octave at twice those frequencies. It does not read the source samples directly or alter their files.

The default pitch frame is 2048 samples with eight-way overlap and periodic Hann windows. Tables and storage are allocated on the control thread when Shimmer is selected, then retained through bypass/Panic. The audio thread allocates nothing and takes no locks. Reduced Quality uses smaller frames against its reduced wet clock so it does not accidentally add over a second of wet latency. The direct signal remains immediate and unchanged. The added pitch-frame delay is confined to the wet octave return; frame processing can smear wet transients and is not an exact reconstruction of Sunday Keys' algorithm.

A simultaneous 220 / 261.625565 / 329.627557 Hz input produced octave peaks at 440 / 523.251 / 659.255 Hz, within 0.5 Hz at 44.1, 48 and 96 kHz. The regression also checks bounded output and complete reset. The full processor's existing dry-identity, independent mix, wet onset, stereo tail, maximum-feedback, Quality and anti-alias tests remain required. Spectral accuracy alone does not prove the musical sound matches Sunday Keys.

A preliminary optimized 48 kHz stereo benchmark took 0.361 CPU seconds for ten seconds of processing, versus 0.055 for the prior grain algorithm on the same execution host. This is a measured increase, not an audio-deadline or device-performance guarantee. Dense multi-channel loading and physical iPad/iPhone performance remain release gates.

The shared processor serves native slots, imported racks and Tonic Shimmer. No saved parameter arrays, rack topology or original samples change. The Shimmer editor now uses the observed FDBK/Mod labels and taller aligned Character/Output panels. Tone remains a Hertz control until Sunday's percentage taper can be measured; merely changing its unit would misrepresent the processing.

Temporary EQ/filter bypasses were restored. A separate StageKeys Steinway Calibration v52.concert is saved in the workspace with original processing restored and recording off. A new controlled amplitude capture still requires the requested idle keyboard/pedal window. No speculative gain or amplitude-law change is included.
