# Native sampler response v6 — StageKeys 0.48

A fixed gain boost hid a time-dependent error: the previous native amplitude envelope decayed faster than MainStage. The converter now uses the concave envelope-to-gain transform while retaining source envelope times. EXS amplitude velocity sensitivity uses half-dB units (the Steinway's raw −52 corresponds to 26 dB), with an explicit MIDI endpoint correction for AUSampler's velocity normalization. Centered layers/zones receive a separate 3.0103 dB output normalization; source master and zone gains remain represented independently.

The actual upgraded preset was rendered through the production audio graph and compared against two MainStage passes, three pitches (60, 74, 86) and five velocities (38, 64, 83, 102, 127). Source filters and EQ were bypassed and the source host curve was −10. Waveform-aligned 100–300 ms windows measured MainStage minus StageKeys at 0.96665–0.98002 dB, minimum correlation 0.99777. StageKeys retains 1 dB of output headroom: accounting for that, this dry sampler measurement is within 0.04 dB. This is not full patch/effects parity or a measured physical MIDI latency result. See Calibrations/Steinway-Response-v48.json.

Reapplying CC7/11 after Panic made byte-identical renders; controller reset was not the level cause. The inspected MainStage amplitude slider was key scaling (source parameter 8), not master volume (parameter 7). The reference key scaling was restored to 0; source master volume remains −6 dB. No patch-name compensation or sample processing is used.

Fresh conversions receive version 6. Existing imports update from the retained, hash-verified original instrument. The upgrade backs up the previous preset, checks generated zone gain and amplitude routes, preserves edited envelope times/curves, and refuses ambiguous source groups or edited gain routes rather than overwriting them. Sample references, sample/loop/key/velocity maps, original PCM and rack effects remain intact. The update is idempotent. Use Import Sounds → Update Converted Sampler Playback for other installed libraries.

Limits: centered output was calibrated; noncenter pan laws, nonzero amplitude high endpoints, all velocity-layer transitions and other EXS envelope/modulation shapes still need independent fixtures. The Lush filter, reverb early reflections/decay, Shimmer under physical-device load and full converted-patch coverage remain release gates. Existing streaming, split-loop and click fixes are retained. No new Shimmer or visual redesign is claimed in this response-focused update.
