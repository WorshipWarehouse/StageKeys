# Release regression gates

Refs #22. Pull requests run universal macOS and iOS Simulator unsigned Release builds, artifact/content validation, the portable parser corpus, the complete default library/conversion/persistence/routing suite, and reverb AddressSanitizer/UndefinedBehaviorSanitizer tests; a push to `main` runs the same set for the merged commit. Each commit gets exactly one run, so a required check name is reported once and stays unambiguous. Jobs have bounded timeouts and obsolete runs cancel. Build logs are retained for 14 days; private samples, user data and instrument recordings are not uploaded.

Run `Tools/verify-release.sh mac /private/tmp/stagekeys-release-mac` or replace `mac` with `simulator` for the same artifact gate locally. The iOS bundle step also runs `Tools/check-app-icon.py`, which refuses an artifact whose Info.plist declares no primary icon, whose compiled `Assets.car` holds no opaque 1024 px rendition under the declared name, or whose loose fallback PNGs are missing, mis-sized or blank; `Tests/test-app-icon.py` exercises those refusals against synthetic bundles in the `processing` job. The committed Xcode project is authoritative; no project regeneration or private sound-library checkout is needed. Tests generate original fixtures at runtime. Private MainStage/Steinway comparison fixtures are deliberately absent from CI.

Unsigned CI artifacts are not public releases. Branch protection must require successful jobs before release. Hardware route/latency tests, physical iPad AUv3 qualification, reference listening, long performance soak, Developer ID signing/notarization and clean-device install remain separate recorded gates. A green workflow cannot establish those properties.

The `library` check compiles a testable core once with `Tests/run-local-library.py`, preserving the shell gate’s complete default Swift/C list. Its outcome artifact and job summary report skips separately. `processing` tests the runner’s failure/skip behavior. No compiled test artifacts are reused from another commit; the four required check names and platform/content/sanitizer gates remain unchanged. See `CI-PROCESS-AUDIT.md`.
