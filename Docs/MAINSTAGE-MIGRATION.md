# MainStage-native library migration (0.37)

StageKeys now imports each supported EXS channel as a reusable native library layer, including its supported channel processing. EQ, compressor, stereo delay, SilverVerb, ClipDist and supported chorus settings are attached in source order; decoded macros retain their bindings. Supported ranges, transpose, pan, mute and sustain behavior accompany the layer. Library save/load and adding the sound to another patch preserve that model instead of reconstructing a bare instrument.

New native EXS imports use unity layer gain, removing the earlier automatic extra −6 dB attenuation. Source faders at unity or silence are represented directly. Other source fader tapers, expression curves, sampler overrides embedded in channel strips, auxiliary buses and unsupported MIDI processors require further translation and appear in conversion notes. This does not establish exact MainStage loudness or effect-circuit parity.

The retired ADG/ADV/ALP import and host-launch workflows, parser, extraction/conversion tools and parser-only tests were removed. Existing saved generic sampler/rack data can still be decoded so personal patches remain recoverable. During this migration, 213 previous sample-import library entries were archived with a full local catalog backup; their audio and personal setlist instances were not deleted. New library browsing focuses on the MainStage sources and native sounds.

A bounded, non-destructive archive scan inspected 358 patches / 427 channels. Nine sampler channels could be staged from the two installed factory Steinways. Fifty-seven EXS channels were blocked by missing/unsupported original instruments, 361 other channels require native synth/processor work, and one archive had no supported channel list. The separate private library pack retains original patch bundles, original EXS and unmodified audio. No sample content enters the app repository or bundle.

The user recording identified wrong-pitch decay audio. EXS logical loop positions must be mapped through separate physical tail storage; see EXS-SPLIT-REGIONS.md. Prepared PCM regions are now compacted into a small number of files instead of hundreds of waveform references, avoiding observed missing hard-velocity audio. Prepared native sampler documents are retained across graph rebuilds, with MIDI controllers restored after reloads. Shared instruments are installed once per pack. Runtime-only PCM caches are removed on normal exit, and abandoned caches with a dead process ID are reclaimed on the next launch.

Validation includes actual PCM byte preservation, shared-file zone offsets, D5 tail pitch, live attacks, controller banks, source processing persistence and native-pack rendering. Unsupported patches are reported, never silently replaced by generic tones or resampled captures. The next work is installing missing source assets, implementing the remaining synth engines/MIDI processors and measuring channel-strip sampler overrides and level response against MainStage.

## Modern processor names and bypass retention

Modern MainStage display names (Channel EQ, Compressor, Stereo Delay, SilverVerb and Clip Distort) are normalized to the existing decoders without changing parameter order or macro slot identity. Paired exports of the reference channel, differing only in the EQ host bypass, identified the UInt32 at device offset 148: zero is enabled, one bypassed. The importer retains that state and warns on unknown encodings. Library roundtrips retain both the bypass and original parameter values. Imported EQ editing now uses the native eight-column frequency/gain/bandwidth layout instead of a generic parameter grid, while retaining its original rack position.

The reference Sampler shows 0 dB, but saving an EXS copy retains the original instrument's −6 dB field even after an output-control change. Consequently this file alone cannot establish the modern host output override. No speculative +6 dB correction is applied. Exact level calibration and modern sampler-state overrides remain open.

## 0.38 independent reverb levels

The archived Two Pianos Steinway channel was opened for reference in MainStage: SilverVerb shows Dry 100%, Wet 51%, matching extended record indices 10 and 11 when index 12 is 1. The old importer instead used legacy Mix 44%, incorrectly setting Dry 56% / Wet 44%. The importer now selects the active mode, preserves independent dry/wet controls and maps their macros separately. Inactive-mode macros remain archived instead of changing the active levels. Unknown modes and invalid independent levels are reported, not guessed. The native reverb tank remains an independent approximation.

The private native pack received eight corrected reverb instances across seven sounds. The installed library templates were updated only when their racks still matched the prior templates; original samples and EXS are unchanged. The separate Steinway comparison patch's SolaVerb was bypassed after confirming the current MainStage piano routes directly to Output 1–2 (its reverb sends belong to the separate Sum channel). Its pre-change setlist was backed up. These fixes correct verified dry-path attenuation and routing, but do not establish exact sampler velocity/host level or proprietary reverb-decay parity.

Validation covers independent versus legacy mode, wet-only MIDI macros, saved rack roundtrips, the full dry impulse level in DSP, source-to-pack rack equivalence and audible finite rendering of nine channels at four velocities. Reverb output controls are grouped side by side in the sound-processing UI.

## 0.39 amplitude velocity and decay measurement

Source EXS amplitude sensitivity (parameter 0x5a) and high-velocity level (0x59) now replace the native template's velocity-to-amplitude route. The current modern Steinway stores −52 dB sensitivity while the template uses −96 dB. This changes soft/hard balance rather than adding a master boost. The separate modern MainStage host velocity curve (the comparison channel stores −10 in its channel strip) remains untranslated; exact loudness parity is not claimed.

The existing-import upgrade checks that the velocity route still has its generated −96 dB scale, inverse concave transform and enabled state. Edited routes are rejected and the preset bytes restored. Sample zones/references, envelopes, patch effects and channel settings are retained, and the optional native amplitude metadata is backward compatible. Library conversion notes are merged instead of losing effect compatibility warnings during a sampler update.

A paired MainStage recording used a fixed-velocity sequence and an isolated wet SilverVerb capture. With Room Size 160, Reflectivity 71%, Density/Time 81%, predelay 17 ms and filters 760–6800 Hz, a 3–9 second tail fit measured MainStage RT60 ≈8.66 s and native StageKeys ≈9.05 s for the captured input. The original dry input was passed through the native reverb for comparison. No global decay factor was inferred from this one setting: the early-reflection response and proprietary circuit still differ. See Calibrations/Steinway-MainStage.json for numerical measurements; original samples are unchanged.

Performance effect power buttons now expose On/Off state to accessibility, including Off for empty slots.

## 0.40 early reflections and host curve retention

Silver Reverb now includes two short reflection paths before the late tank diffusion. They use separate delay partitions, room-scaled timings and a bounded shorter decay, with reflectivity controlling their contribution. Dry level and predelay remain independent. This is an independent approximation, not Apple's algorithm. On the retained paired recording, the first-second RMS changed from −47.46 to −39.84 dB against MainStage's −38.95 dB. Seconds 3–9 stayed within 0.01 dB of the prior native tail. The second-second response still differs substantially; full early-envelope and spectral parity are not established. Original source audio is unchanged. The common native DSP applies to existing and future imported racks without rewriting patch effects.

The channel-strip reader now retains host AMP_VELOCITY_CURVE (0x183) separately from the shared EXS instrument. Bounded MELC sampler records must agree; conflicting or out-of-range values are rejected. This optional per-rack metadata survives library/setlist roundtrips. Nonzero curves are explicitly reported as awaiting response calibration and are not applied as a guessed MIDI remap, which could select different sample zones and filters. Live A/B calibration at curve −10 versus 0 remains necessary before activating this response. Existing imports are not silently rewritten.

Sound settings now use wide minus/value/plus controls with directly editable values for transpose and native voice count, and a separate Audio Output heading above Pan, based on a fresh reference-app inspection. Imported instruments retain their own voice management. Attack Smoothing is available under More Sound Controls so it does not displace Audio Output in the main settings layout.
