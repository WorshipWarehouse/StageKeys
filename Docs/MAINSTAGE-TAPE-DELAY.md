# MainStage clean Tape Delay translation — revision 1

Refs #6 and #10. Observed on MainStage **4.3.1**, macOS, 2026-10-29, in a disposable copy of the existing calibration concert (`/private/tmp/StageKeys Fader Calibration.concert`), Steinway Reference / Grand Piano / Tape Delay. Read the accessible Controls view, changed one control at a time, saved the disposable concert, and compared its CST parameter records. Original user concert/sample files were not edited. No matched audio capture or null test was performed; sample rate/buffer/output route do not establish anything for these serialized-control measurements.

Observed parameter fields: feedback 3 (51%), high/low cut 4/5 (1900/170 Hz), sync switch 6, note denominator 7 (4 for quarter, 8 for eighth), deviation 8 (percentage), stored source tempo 15 (120 BPM), independent dry/wet 19/20 (100/0%, then 70/1%). In free mode, 250 ms saved denominator 8/deviation 0; 260 ms saved denominator 8/deviation +4%. This supports `beats = 4 / denominator * (1 + deviation/100)`; synced playback uses current host tempo, free playback uses stored source tempo. Freeze changed field 14 from 0 to 1. Controls were restored and serialized values rechecked: sync on, quarter, zero deviation, dry 100%, wet 0%, freeze off.

The importer now activates the static clean subset with explicit timing, feedback/filter values and independent output gains. Both gains may be zero (exact silence) or unity (unattenuated dry plus wet); they are not forced into a complementary mix. New optional fields preserve old delay documents with their previous complementary-mix behavior. Level changes ramp over 20 ms; initial configuration uses the saved levels. Dry/wet and supported feedback CC macros use source percentage units and retain their saved positions. The imported controls show separate Dry/Wet knobs instead of a misleading complementary Mix knob.

Unverified modulation, freeze, diffuse head, non-default clipping/spread and unknown nonzero states remain rejected with an explicit processing note. Supported denominators are the ordinary whole/half/quarter/eighth/sixteenth/thirty-second/sixty-fourth values; other encodings remain unsupported. Native times/feedback/filter bounds are checked, never silently clamped during translation. Source patch tempo/output buses remain separately qualified conversion work.

The native delay/feedback filters and safety limiting are independent. Tape saturation, modulation, smoothing, exact filter response and MainStage transient/decay equivalence are **not** established. This is active parameter translation, not complete Tape Delay sonic parity.

`MainStageTapeDelayTests` checks measured timing/levels, CC macros, persistence, legacy defaults and unsupported-state refusal. `DelayIndependentLevelsTests` checks stereo impulse arrival/amplitude, exact zero levels and smooth automation at 44.1/48/96 kHz; it runs in the normal C corpus and ASan/UBSan effect suite. Original source bytes are unchanged by decoding. Full MainStage effect parity remains open in #10.
