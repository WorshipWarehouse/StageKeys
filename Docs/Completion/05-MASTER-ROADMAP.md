## Critical path and release cut

Proposed Mac critical path: **00 → 03 → 04 → 05 → 12 → 21 → 22**, joined by **01 → 08 → 09 → 10 → 16 → 21** and the **06/07** callback/headroom gates. #110 live validation (02) also joins 12. No timing estimate can be credible until task 03 isolates failures and the owner sets the rig/content scope.

Routing (11), preload (15), batch/checkpoints (17–18), portable setlists (23) and stronger source-fidelity ambitions can lengthen that path only if included in the advertised release. Excluding them requires an explicit supported-scope decision and honest UI/docs; it does not make the original issue complete. Mobile has a separate conditional chain **19 → 20 → mobile part of 21/22**, with #105 still intentionally deferred. Cloud, AI and non-4/4 are not assumed v1 requirements.

Before taking any task: read its issue draft and linked current implementation, refresh remote state, confirm prerequisites, reproduce a failing criterion or missing evidence, and define isolated file ownership. Keep every pass/skip/failure and actual commit in the evidence ledger. Do not infer task completion from the roadmap table.
